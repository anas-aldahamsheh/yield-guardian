# Knowledge: wafer-pattern causes from open-access literature

- `pattern_causes.json`: the table the API serves (`GET /api/v1/knowledge/patterns`, contract `PatternCauses`). Edit this file.
- `pattern_causes.md`: the same table for people to read, generated by `render_pattern_causes.py`.
- `render_pattern_causes.py`: loads the table with the API's own loader, checks the curation rules and writes the Markdown:

  ```
  uv --directory services/api run python ../../docs/knowledge/render_pattern_causes.py
  ```

## How the sources were checked (2026-10-14)

Every source was opened on its publisher's or arXiv's page. Title, authors, venue, year, DOI and licence were read there, not recalled. Each quote was read twice, in separate fetches, and kept only when both reads returned the same words. Quotes are short spans (at most 125 characters) used to cite the claim. Nothing longer is copied. Where a paper cites older work for a statement, the location says so; those older papers (for example Hansen and Thyregod 1998, Wang and Bensmail 2006, Piao et al. 2018) are not open access and were not read.

Not used: the original WM-811K paper (Wu, Jang and Chen, IEEE Transactions on Semiconductor Manufacturing, 2015), because it is not open access.

## Evidence strength (the `confidence` field)

- **medium**: two or more papers state the link, citing different earlier sources.
- **low**: one paper states it, or one unreviewed preprint states it without a citation.
- **high**: not used. No source read gives direct experimental evidence that a pattern comes from a cause.

## Caveats

- These are hypotheses to check against a fab's own process history, not diagnoses.
- Most statements are one-line remarks in the introduction of a machine-learning paper, often citing older process work.
- Several papers trace back to a few older sources. "Two papers agree" therefore means less than two independent experiments.
- The only source for Loc and Near-full is an unreviewed preprint that cites nothing for these statements. Those rows are marked low.
- The Random row includes a statement about random noise dies (Kim and Kim), not about the Random class itself. The location says so.
