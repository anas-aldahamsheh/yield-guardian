# Yield Guardian

An investigation console for semiconductor fab yield engineers. It replays real production data, flags wafers likely to fail before final test, narrows hundreds of sensors to the few associated with failure, detects drift, reads wafer-map defect patterns, and has an AI investigator write an evidence-linked report that an engineer approves.

Built for the AMD Developer Hackathon: ACT III, track Intelligent Industry.
