# WM-811K: attribution

The wafer maps in `wafers.parquet` are a small derived subset of WM-811K: every wafer of
479 lots (10253 wafers), unmodified die values (0 no die, 1 pass, 2 fail).

- **Dataset:** WM-811K, collected by the MIR Lab (Multimedia Information Retrieval Lab),
  National Taiwan University, from real fab production.
- **Citation:** Wu, M.-J., Jang, J.-S. R. and Chen, J.-L. (2015). Wafer map failure pattern
  recognition and similarity ranking for large-scale data sets. IEEE Transactions on
  Semiconductor Manufacturing, 28(1), 1-12. https://doi.org/10.1109/TSM.2014.2364237
- **Retrieved from:** Kaggle mirror https://www.kaggle.com/datasets/qingyi/wm811k-wafer-map
  (the original MIR Lab page returned HTTP 404 on 2026-10-14).
- **Licence:** the Kaggle mirror lists CC0-1.0, set by the uploader, not by the authors. No
  licence from the original authors could be retrieved, so we redistribute only this small
  derived subset, with this attribution, for demonstration and research.
