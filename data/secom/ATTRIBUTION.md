# SECOM: attribution

The three files in this folder (`secom.data`, `secom_labels.data`, `secom.names`) are
redistributed unmodified from the UCI Machine Learning Repository.

- **Dataset:** SECOM
- **Authors:** Michael McCann, Adrian Johnston
- **Source:** UCI Machine Learning Repository, dataset 179,
  <https://archive.ics.uci.edu/dataset/179/secom> (archive
  <https://archive.ics.uci.edu/static/public/179/secom.zip>)
- **DOI:** <https://doi.org/10.24432/C54305>
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0),
  <https://creativecommons.org/licenses/by/4.0/>. Licence statement on the dataset page,
  retrieved 2026-10-14: "This dataset is licensed under a Creative Commons Attribution 4.0
  International (CC BY 4.0) license. This allows for the sharing and adaptation of the
  datasets for any purpose, provided that the appropriate credit is given."
- **Citation:** McCann, M. and Johnston, A. (2008). SECOM [Dataset]. UCI Machine Learning
  Repository. https://doi.org/10.24432/C54305
- **Changes:** none. The files are byte-identical to the ones in the UCI archive (CRLF line
  endings kept); their SHA-256 values are listed in `data/manifest.json`.
